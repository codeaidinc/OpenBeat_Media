# 運営者＝データ管理者（自己ホスト時）— OpenBeat Media（無料OSS版）

## 1. 製品の前提
OpenBeat Media（無料OSS版・Apache-2.0）は、ローカルで動作する静的サイト生成ツールです。

- ローカルの「Studio」（Python/Flask）で記事を編集し、`output/` に静的HTMLを書き出します。
- **既定の生成サイトは、個人データを一切収集せず、Cookieを設定せず、トラッカー・解析・外部呼び出しを含みません。**
- AI機能・外部APIコール・テレメトリはありません。

## 3. 自己ホスト運営者がデータ管理者である理由
生成された静的サイトを**自分のドメイン／ホスティング（例: Cloudflare Pages）で公開する主体**は運営者です。したがって、以下について運営者が**データ管理者（controller）**として責任を負います。

- **公開コンテンツ**：記事本文、画像、見出し、メタデータ。
- **リンク先**：本文・出典に記載した外部リンクの適切性。
- **追加した第三者サービス**：運営者が後から足す解析（Google Analytics 等）、外部フォント、埋め込み（YouTube/X 等）、問い合わせ・ニュースレターフォーム。これらは Cookie や個人データ処理を発生させ得ます。
- **アクセスログ**：ホスティング事業者（例: Cloudflare）が取得するアクセスログ・IPアドレス等の取り扱い。

CODEAIDは、これら運営者が追加・公開する要素のデータ管理者ではありません。CODEAIDの責任は、ツール自体の安全性・品質・セキュリティに限られます。

## 4. 既定構成での個人データ
- **個人データ収集：なし**（フォーム・ログイン・コメントなし）
- **Cookie：なし**
- **解析・トラッカー：なし**
- **外部リソース読み込み：なし**（既定テーマはインラインCSS。外部フォント・CDNを使いません）

この既定状態では、運営者に GDPR / UK GDPR / 個人情報保護法上の追加義務（プライバシーポリシー掲載・同意取得等）は原則発生しません。ただし**ホスティング事業者のアクセスログ**は別途確認が必要です。

## 5. 運営者が第三者サービスを追加する場合の義務
解析・外部フォント・埋め込み・フォーム等を追加した時点で、運営者は以下を**自ら**実施する必要があります。

1. プライバシーポリシーの掲載（`compliance/PRIVACY_TEMPLATE_ja.md` を参照）。
2. Cookie / トラッキングの同意取得（EU・英国では原則オプトイン）。
3. 適法な処理根拠の特定（GDPR第6条 等）。
4. 任意のプライバシー通知パーティシャル（`themes/default/_privacy_notice.html`）の有効化。
